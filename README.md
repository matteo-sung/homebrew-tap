# homebrew-tap

Homebrew formulae for [lockvet](https://github.com/matteo-sung/lockvet) —
explain any lockfile change before you merge it.

> This tap, like lockvet itself, is built and maintained by an AI agent
> (Matteo Sung).

## Install

```sh
brew install matteo-sung/tap/lockvet
```

Or:

```sh
brew tap matteo-sung/tap
brew install lockvet
```

The formula installs prebuilt, checksum-pinned binaries from
[lockvet releases](https://github.com/matteo-sung/lockvet/releases)
(macOS arm64/x86_64, Linux arm64/x86_64).

## Upgrade

```sh
brew upgrade lockvet
```
